# Ahmad-Zahir Music Streaming App

![App Demo](AhmadZahir.gif)

## Overview
The **Ahmad Zahir Music Streaming App** is a fully functional Android application built with Java and Android Studio. The app provides easy access to the works of legendary Afghan pop star Ahmad Zahir, combining a clean, responsive UI with solid software engineering practices.  

## Features
- 🎵 Stream and play Ahmad Zahir’s music directly from the app  
- 📱 Responsive layouts optimized for multiple Android device sizes  
- ⚙️ Built using **Java** and **Android Studio** for native Android performance  
- 🧩 Applied **object-oriented programming principles** and **Android architecture components** to ensure maintainability and scalability  
- 🛠️ Clean architecture and modular design for easier enhancements  
- 🚀 Smooth, user-friendly interface with intuitive navigation  

## Getting Started

### Prerequisites
- Android Studio (latest version recommended)  
- Java JDK (version 11 or above)  
- Android device or emulator running Android 8.0 (API level 26) or above  

### Installation & Running
```bash
# Clone the repo
git clone https://github.com/Wahid-Haidari/Ahmad-Zahir-App.git

# Open in Android Studio
cd Ahmad-Zahir-App
```
- Sync Gradle dependencies  
- Run the app on an emulator or connected Android device
